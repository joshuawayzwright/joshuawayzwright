# Security Policy

## Scope

This repository contains Joshua Wright's GitHub profile content and repository-management automation.

Do not commit passwords, API keys, GitHub tokens, signing keys, private keys, customer data or other secrets.

## Reporting

For a security issue in one of the public projects, use the relevant repository's private vulnerability-reporting mechanism where available. Do not publish credentials or exploitable security details in a public issue.

## Automation safety

Migration and protection scripts are designed to fail closed when required repositories or permissions are missing. Review account-level changes before execution and use least-privilege GitHub authentication.
