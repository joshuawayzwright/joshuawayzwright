## Product standard

Every repository must ship as a real usable product, not a placeholder:

- working browser application
- responsive mobile layout
- README with screenshots/demo section
- SECURITY.md
- CONTRIBUTING.md
- CHANGELOG.md
- privacy/data-handling statement
- explicit AI capability boundary
- source download instructions
- quality CI pinned to immutable action SHAs
- no committed secrets
- no fake download counts, testimonials, users, ratings or revenue claims
- no fake APK or binary
- commercial CTA to The Solo Service Provider where relevant

## Discovery strategy

Use descriptive repository names and README copy that match real search intent. Cross-link related products sparingly. AI Download Center may list the apps once their independent repositories are public and operational.

## Release standard

Start at v0.1.0 for a usable initial release. Move to v1.0.0 only after the product interface and documented behavior are stable. Release archives must correspond to tagged source.

## Android

Do not publish an APK until a genuine Android build/signing pipeline exists. Browser/PWA distribution is preferred initially because it is auditable and immediately usable on desktop and mobile.
